# 教材ライブラリ

学びのそばに、ちょうどいい道具。児童の学習用HTMLと、先生の仕事用HTMLをまとめた公開ライブラリです。

## できること

- 教科・学年・種類・キーワードから教材を検索
- お気に入り・最近つかった教材を端末内に保存
- 先生用パスワードで、児童用と先生用の両方を表示
- HTML教材を独立したフォルダーで追加。画像・CSS・JavaScript一式にも対応
- PC・iPad・スマートフォンの画面幅に対応

初期収録は「たし算カード」「授業準備チェック」の組込み見本です。

## 先生モードについて

パスワードはメニュー表示の切り替えに使います。**HTML、紹介情報、画像を非公開にする仕組みではありません。** URLやこの公開保存場所からファイルを取得できます。児童の個人情報、未公開資料、接続情報は置かないでください。

パスワードの原文を公開コードに含めず、照合用の値を `config/teacher-mode.json` に置いています。PC内のパスワードメモは `.local` に保存し、GitHubへ送信しません。

## 開発用コマンド

Node.js 24、pnpm 11.25.0を使います。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm preview
```

初回の制作環境は準備済みです。別のPCで新しく始める場合も、既存の `config/teacher-mode.json` を使って生成できます。先生用パスワードを設定し直す場合は `pnpm password` を実行し、生成・公開し直します。

## 公開

GitHub Pagesの公開元をGitHub Actionsに設定します。mainへの反映後、検査が成功した版だけを公開します。公開版には `dist` の内容だけを使用し、 `.local` や元の教材保管先は取り込みません。

## 利用条件

組込み見本は授業や仕組みの確認に使えます。コードの再配布などに関するライセンスは未設定です。今後追加する教材についても、それぞれに記載する利用条件を確認してください。

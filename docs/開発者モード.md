# 開発者モード

制作PCで `教材ライブラリを開く.bat` を開き、ページ下部の「開発者用」を選びます。初回は先生用とは別に12文字以上のパスワードを設定します。先生用と開発者用はそれぞれの画面から開けます。

## 公開サイトから取り下げる

1. アプリの行で「非公開にする」を選び、「設定を保存」を押します。
2. 「公開設定をコピー」を押し、「GitHubで公開設定を開く」を選びます。開いた編集欄の内容を置き換え、変更を保存します。普段どおり変更を main に反映すると、GitHubで検査と公開が始まります。
3. GitHubの「Actions」で公開が終わったら、公開サイトの一覧とアプリのURLを確認します。

次回の公開時に、一覧、検索、お気に入りの表示から外れ、GitHub Pagesへの配布からHTML・画像などが取り除かれます。公開リポジトリの元ファイルや公開済みのソース履歴はGitHubに残ります。端末に入っているオフライン版や以前にダウンロードされたコピーは引き続き使えることがあります。再開するには「公開する」を選び、同じ手順で反映します。

## 保存なしで試す

アプリの行で「保存なしで開く」を選びます。端末内の記録や作品にアクセスできない画面で起動します。公開サイトから取り下げた教材も制作PCから試せます。保存が必要な機能は、その機能が使えないときの案内や挙動を確認できます。

開発者画面とパスワード設定は制作PCで扱います。パスワードはPC内の `.local/developer` に照合用の形式で保存します。

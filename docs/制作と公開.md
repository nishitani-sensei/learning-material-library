# 制作と公開

## 構成

TypeScript＋Viteの静的サイトです。サーバーへの入力保存や会員登録はありません。教科・分類・学年・種類・キーワードを組み合わせて検索し、紹介情報から教材一覧を生成します。

先生用一覧はパスワードを確認してから読み込みます。タブ内の切替状態をsessionStorage、お気に入り・最近の教材IDをlocalStorageへ保存します。保存不可の端末でも教材を開けるようにします。

一覧と詳細はURLのクエリで表現し、GitHub Pagesに書き換え設定を追加せず、直接URLと再読み込みを使えるようにしています。生成物のパスは相対指定です。

## GitHub Pages

保存場所：`nishitani-sensei/learning-material-library`。

GitHubの Settings → Pages → Build and deployment で Source を GitHub Actions に設定します。`.github/workflows/pages.yml` が検査・生成・公開を行います。変更案では検査だけを実行し、mainへの反映後に検査した同じ生成物を公開します。

## 検査範囲

実施した検査の結果は `docs/確認結果.md` に記録します。実機未確認の項目を、模擬画面や自動検査だけで確認済みにはしません。

Windows PCのブラウザー、iPadのSafari、学校回線での利用を分けて確認します。公開後はホーム、児童用教材、先生モード、先生用教材、各画像と戻る操作を確認します。

## 先生用パスワードの変更

`pnpm password` で8文字以上の新しい値を設定し、`pnpm build` で作り直してGitHubへ反映します。公開する設定は照合用の値だけです。`.local` の原文メモをアップロードしません。公開設定の照合値が変わると、前の切替状態も次の読み込みで無効になります。

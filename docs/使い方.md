# 先生向けの操作案内

## 教材を使う

ホームの教科ボタンから選ぶか、検索欄にことばを入れて「さがす」を押します。学年や教材の種類でも絞れます。「ひらく」で教材へ、「使い方」で説明へ進みます。

教材の「ライブラリへ戻る」から戻ると、検索条件と一覧の位置が戻ります。ブラウザーの戻る操作も使えます。

## 自分の本だな

教材の♡でお気に入りに追加・解除します。使った教材は「最近つかった教材」に並びます。この端末のブラウザー内に保存するため、別の端末には引き継がれません。ブラウザーの保存データを消すと、本だなの登録も消えます。

## 先生用を使う

右上の「先生用をひらく」から先生用パスワードを入力します。先生用と児童用の両方が表示されます。間違えた場合はその場で入力し直せます。

この制作PCの初期パスワードは、制作フォルダー内の `.local/先生モードのパスワード.txt` にあります。公開サイトやGitHubにはこのメモを置きません。

使い終わったら「先生モードを終了」を押します。先生用の教材は、お気に入りや最近使った教材からも表示されなくなります。先生モードの終了は、教材のチェックなどを削除する操作ではありません。

パスワードは一覧表示を切り替えるためのものです。ファイル自体へのアクセス制限には使いません。

## PC内で開く

制作PCでは「教材ライブラリを開く.bat」を使います。起動後は `http://127.0.0.1:4188/` で開けます。公開サイトとPC内のサイトでは、ブラウザーの保存場所が別になります。
